# Historical canvas command catalog

Status: retired · Last updated: 2026-11-14

The former Blender-first P0 command catalog was discarded. It is intentionally
not preserved as a competing interaction contract.

Current command behavior and placement are defined by:

- [spec.md](spec.md) for Slicer-standard behavior and shortcuts;
- [ui-journeys.md](ui-journeys.md) for primary control ownership and journeys;
- [plan.md](plan.md) for the proposed implementation sequence.

Do not implement a command, shortcut, or persistent control from this file.
